# Checklist Entrega 3 — criterios de evaluación

Fuente: https://xacarana.com/cursos/aplicaciones_moviles/#/6/2

- (10%) Asistencia a clase: llevar app corriendo en el físico target.
- (10%) Repo y colaboración en nuevo equipo:
  - `main` protegida, ramas `feat/login`, `feat/rachas`, `feat/play-listing`, etc.
  - Cada integrante con commits propios, PR con revisión, `README.md` con instrucciones.
  - No subir `*.jks`, `local.properties`, `/build` (ya en `.gitignore`).
- (10%) Diseño en papel: 8 fotos en `docs/wireframes_papel/`: `01_login.jpg` … `08_creditos.jpg`.
- (10%) Figma digital: flujo + wireframe gris + UI color, link en `README.md`.
- (20%) Montaje Android Studio: proyecto abre, sincroniza Gradle 8.7 / AGP 8.5.2 / Kotlin 2.0.20, corre en físico.
- (20%) Funcionalidades: login/registro local, menú con racha, listado clases, detalle, formulario tarea, notas + metas, ajustes, créditos. Demo sin internet.
- (20%) Publicación Play: acceso por `lasmovies@gmail.com`, ficha en `docs/play/`, `.aab` firmado, track Prueba interna.

## Orden sugerido de cierre
1. Fotos papel + link Figma.
2. Icono + 4 capturas 1080px + feature graphic en `docs/play/`.
3. Generar `.aab` firmado (no subir el `.jks`).
4. Subir a Play > Prueba interna, capturas de evidencia para `docs/PRESENTACION.md`.
